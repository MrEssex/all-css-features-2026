@font-face { font-family: "Fallback"; src: local("Arial"); size-adjust: 107%; ascent-override: 90%; descent-override: 22%; line-gap-override: 0%; }

Reshapes a local fallback font to match the metrics of the webfont it stands in for, so the swap causes no reflow. This is how zero-layout-shift font loading is done without blocking render.
